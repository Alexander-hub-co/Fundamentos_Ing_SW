# Capturas de las pantallas del sistema

**Parquivo** · Fundamentos de Ingeniería de Software (12946) · 2026-2

Veintitrés capturas del sistema funcionando, tomadas a 1440×900 con densidad 2×
—imágenes de 2880 px de ancho— en el tema oscuro, que es el de partida. Cada
archivo es la pantalla completa, no sólo lo que cabe sin desplazarse.

No son maquetas: son el sistema real, con datos de prueba.

Los identificadores que se ven en las capturas —`PQV-001`, `PCH-001`, `PEC-002`—
son los códigos legibles del sistema: la sigla del establecimiento y un
correlativo propio de ese establecimiento. Los nombres y correos son datos de
prueba.
